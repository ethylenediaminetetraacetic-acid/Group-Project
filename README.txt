-the file lib\AbsoluteLayout.jar belongs to NetBeans software, it is required to run the GUI.

Instructions to run the GUI:

1. Compile:
   # Windows
   javac -cp "lib/*" -d bin src/project/banana/*.java
   # Linux / Mac
   javac -cp "lib/*" -d bin src/project/banana/*.java

2. Run:
   # Windows
   java -cp "bin;lib/*" project.banana.MainGUI
   # Linux / Mac
   java -cp "bin:lib/*" project.banana.MainGUI

note: make sure you are in the right path.
e.g., C:\Users\(user)\Documents\GroupProject2ndTerm
